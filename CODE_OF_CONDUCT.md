# Code of conduct

TaskSparkle is a small project and this note is short on purpose.

Be decent to each other. Argue about the work, never about the person who did it. Assume the other person means well until they show otherwise. Harassment, insults and personal attacks have no place here, in issues, pull requests or anywhere the project is discussed.

The maintainer enforces this note. A comment or thread that breaks it can be hidden or removed, and a person who keeps breaking it can be blocked from the project. If something here makes you uncomfortable, use GitHub's report route on the comment itself or raise it with the maintainer through GitHub.

That is the whole of it. The project stays friendly by people acting that way, not by this page being long.
