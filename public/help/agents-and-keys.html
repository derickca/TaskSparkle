Agents and keys

Your agent works the same boards you do, under its own key.

Setting up

Sign in, open Settings, then Set Up Agent. The page holds short instructions written for your agent: copy them into it. When it asks for a key, select Add a key on that page, give the key a name, and copy the full key when it shows. It shows once. Paste it into the secret field your agent shows you, and your agent connects.

What a key can do

Nearly everything you can: read your boards, make and edit cards, move them between columns and boards, run checklists, add links and leave comments. Work an agent makes wears its key's name, so you can always tell whose hand did it.

What a key cannot do

A key can never make, rename or revoke keys — that stays with you, in the app. It cannot change your sign-in or delete your account. A leaked key cannot lock your other agents out.

More than one key

You can hold up to ten named keys, one per agent say. Revoking a key in Settings stops that one key at once. The others keep working.
