The emailed link

The link is how you sign in.

What it is

When you ask to join or sign in, we email a link to the address you type. Tap it and you are in. It works once, and it goes only to that address — nobody can ask for your link to be sent anywhere else.

If it expires

A link stops working a short while after it is sent. Ask for a new one on the sign-in page. Asking again is always fine, and the new link replaces the old one.

If it never arrives

Look in your spam folder first. Then check the address was typed the way you meant it. Then ask for a new link. If links still do not reach you, tell us through Feedback and name the address you used.
