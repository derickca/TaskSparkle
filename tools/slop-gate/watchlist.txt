# each stand in a checked source named there: Wikipedia, "Signs of AI

# The list grows only by a checked source, recorded beside the entry.
# The audit file's "Proposed additions from the side-chat review
# round" section stands at the end of this file, in the [proposed]
# section, with the distinction exactly as that file states it:
# PROPOSED, unruled — nothing in that section is ruled, and each item
# waits for the owner's judgement with the standards. Entries there
# are scanned and reported; they never fail the gate. An item becomes
# enforced only when the owner rules it and it moves into the ruled
# sections above, in the same act as the standards change.
#
# Format: one entry per line. Blank lines and lines starting with #
# are ignored. Entries match case-insensitively on word boundaries,
# in the page's own words (verbatim quotes and furniture are scanned
# into separate buckets and never fail a page — see slop-gate.py).
#
# An entry starting with ~ is sense-limited: the source names the word
# only in one sense, and the literal use is not a hit ("A literal use
# the sources exclude — a real key, a real landscape — is not a hit;
# the abstract use is."). A match fails the gate unless an exemption
# fingerprint for that exact sentence on that exact page stands in
# watchlist-exemptions.json with its reason — the fleet's scanner
# practice, used for literal uses of sense-limited entries and for
# known findings in already-published text: an exemption covers that
# line on that page; the same words anywhere new still block.
#
# An entry starting with re: is a regular expression (a stock shape).
# An entry starting with ^ matches only at a sentence's start.
